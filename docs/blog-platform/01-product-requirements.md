## 2. 项目背景

用户希望建设一个高颜值、功能完整、SEO 友好、后台强大的个人博客平台。

该平台不仅用于发布文章，还用于展示个人品牌、项目作品、技能经历、社交入口和个人影响力。

平台采用前后端分离架构：

- 前台博客端面向访客，强调美观、可读性、SEO 和性能。
- 后台管理端面向博主和管理员，强调完整、稳定、易操作。
- 后端 API 使用 C# / ASP.NET Core 实现。
- 数据库使用 PostgreSQL。
- 支持 Markdown 编辑。
- 支持图片、视频、附件上传。
- 支持访客评论。
- 评论、留言、联系表单等提交入口必须具备反灌水能力。

---

## 3. 产品定位

本项目定位为一个：

> 现代化个人博客 + 个人品牌官网 + 内容管理系统 CMS + 作品集展示平台。

它不是单纯的文章列表网站，而是具备完整内容运营能力的个人站。

## 4. 产品目标

### 4.1 内容发布目标

- 支持博主使用 Markdown 编写文章。
- 支持文章草稿、发布、下架、置顶、推荐。
- 支持文章分类、标签、归档。
- 支持封面图、摘要、SEO 信息。
- 支持文章内图片和视频展示。

### 4.2 个人展示目标

- 支持个人主页。
- 支持关于我。
- 支持技能标签。
- 支持工作/教育经历。
- 支持项目展示。
- 支持社交链接。
- 支持联系方式。
- 支持友情链接。

### 4.3 互动目标

- 支持访客评论。
- 支持评论审核。
- 支持评论回复，可选。
- 支持评论点赞，可选。
- 支持评论举报或标记垃圾评论。
- 禁止灌水和机器人刷评论。

### 4.4 后台管理目标

- 支持文章管理。
- 支持分类标签管理。
- 支持评论审核。
- 支持媒体库。
- 支持个人页面配置。
- 支持项目展示管理。
- 支持友情链接管理。
- 支持 SEO 配置。
- 支持基础数据统计。
- 支持管理员登录和权限控制。

### 4.5 布局与响应式目标

- 前台页面必须同时适配电脑端、平板端和手机端。
- 桌面端采用宽屏内容容器、模块化首页和清晰的信息层级。
- 平板端保持双列或卡片网格布局，同时保证触控区域足够大。
- 手机端采用单列布局、底部或抽屉式导航、简化信息密度。
- 首页支持管理员自定义模块顺序、模块显示 / 隐藏和模块数据源。
- 内页、列表页、详情页也支持一定程度的模块化配置。
- 自定义页面支持后台创建、编辑、预览、发布、下架和删除。
- 首页顶部导航栏支持后台自定义菜单项、排序、分组、是否新窗口打开。
- 页脚支持版权说明、友情链接、备案号、公安网备案号、ICP 备案号、社交入口等管理。

---

### 4.6 视觉与审美目标

- 前台界面符合 2026 年审美趋势：干净、克制、轻科技感、强可读性。
- 支持后台自定义主色调，并自动应用到导航、按钮、链接、标签、选中态。
- 视觉风格建议包含：
  - 柔和渐变背景。
  - 玻璃拟态卡片。
  - 细腻阴影。
  - 圆角模块。
  - 科技感线条或网格装饰。
  - 高对比但不刺眼的文字层级。
  - 桌面端留白充足，移动端信息紧凑。
- 前台视觉必须服务于 SEO 和阅读体验，不能牺牲可访问性。

---

### 4.7 访问统计与访客记录目标

- 每篇文章、每个自定义页面、分类页、项目页等都需要统计浏览数。
- 文章详情页展示阅读数量。
- 后台仪表盘展示今日访问量、昨日访问量、总访问量、热门页面、来源分布。
- 后台提供访问者记录管理。
- 访问者记录应记录访问时间、页面路径、IP Hash、User-Agent、Referer、设备类型等。
- 访问者记录支持按时间范围、页面路径、设备类型筛选。
- 访问者记录支持自动清理策略，例如默认保留 30 天，超过期限自动删除。
- 阅读数统计需要避免同一访客短时间重复刷高阅读数。
- 访问统计不应影响页面首屏加载和 SEO 抓取。

## 6. 核心业务流程

### 6.1 文章发布流程

```text
管理员登录后台
 ↓
进入文章管理
 ↓
新建文章
 ↓
填写标题、摘要、Markdown 正文
 ↓
上传封面图
 ↓
设置分类、标签、SEO
 ↓
保存草稿或预览
 ↓
发布文章
 ↓
前台生成可访问文章页面
 ↓
搜索引擎可抓取文章页面
```

---

### 6.2 访客评论流程

```text
访客打开文章详情
 ↓
填写昵称、邮箱、评论内容
 ↓
前端基础校验
 ↓
完成验证码或行为验证
 ↓
提交评论 API
 ↓
后端校验验证码
 ↓
后端执行频率限制
 ↓
后端执行内容过滤
 ↓
后端判断是否进入审核
 ↓
评论进入待审核或已发布状态
 ↓
管理员可在后台审核评论
```

---

### 6.3 媒体上传流程

```text
管理员进入媒体库或 Markdown 编辑器
 ↓
选择图片 / 视频 / 附件
 ↓
前端校验文件类型和大小
 ↓
上传文件
 ↓
后端校验 MIME 类型
 ↓
后端生成安全文件名
 ↓
后端保存文件到存储目录
 ↓
后端写入 media 表
 ↓
返回文件 URL
 ↓
文章或页面引用文件
```

---

### 6.4 个人页面配置流程

```text
管理员进入个人页面配置
 ↓
编辑头像、简介、技能、经历、社交链接
 ↓
保存配置
 ↓
数据库更新 profile_sections 表
 ↓
前台读取配置
 ↓
关于我页面和个人首页模块更新
```

## 9. 非功能需求

### 9.1 性能需求

| 指标 | 目标 |
|---|---|
| 首页首屏加载 | < 2 秒 |
| 文章详情页首屏加载 | < 1.5 秒 |
| 常规 API 响应 | < 300ms |
| 图片资源 | 懒加载 |
| 视频资源 | 懒加载 |
| 列表数据 | 分页加载 |
| 热点数据 | 缓存 |

---

### 9.2 安全需求

- 后台接口必须鉴权。
- 管理接口必须校验角色权限。
- 评论接口必须限流。
- 评论接口必须验证。
- 上传接口必须校验文件类型和大小。
- Markdown 渲染必须清洗。
- 评论渲染必须清洗。
- 禁止用户控制文件路径。
- 数据库查询禁止 SQL 拼接。
- 所有敏感操作记录审计日志。

---

### 9.3 可维护性需求

- 前后端职责清晰。
- API 命名统一。
- 数据库结构可迁移。
- 前端组件可复用。
- 后台菜单可配置。
- 日志结构清晰。
- 错误码统一。

## 11. 验收标准

### 11.1 前台验收

- 首页可以正常访问。
- 文章列表可以分页浏览。
- 文章详情可以正常阅读。
- Markdown 渲染正确。
- 图片懒加载正常。
- 视频可以播放。
- 分类、标签、归档页面正常。
- 搜索页面正常。
- 关于我页面正常。
- 项目展示页面正常。
- 移动端适配正常。
- SEO Meta 信息正常。
- Sitemap 可以访问。
- Robots 可以访问。

---

### 11.2 后台验收

- 管理员可以登录。
- 管理员可以新建文章。
- 管理员可以编辑文章。
- 管理员可以发布文章。
- 管理员可以上传封面图。
- 管理员可以管理分类标签。
- 管理员可以审核评论。
- 管理员可以删除评论。
- 管理员可以上传图片和视频。
- 管理员可以配置个人页面。
- 管理员可以配置 SEO。
- 后台权限校验正常。

---

### 11.3 反灌水验收

- 未通过验证码不能提交评论。
- 同一 IP 频繁提交会被限制。
- 空评论不能提交。
- 纯表情评论不能提交。
- 纯链接评论不能提交。
- 重复评论会被限制。
- 包含敏感词评论进入审核。
- 包含链接评论进入审核。
- 后台可以查看和删除垃圾评论。

---

### 11.4 性能验收

- 首页首屏加载小于 2 秒。
- 文章详情页首屏加载小于 1.5 秒。
- 常规接口响应小于 300ms。
- 图片和视频资源按需加载。
- 列表接口分页正常。
- 数据库查询有索引。
