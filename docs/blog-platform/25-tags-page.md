# 25. 标签云页设计规格

路由：`/tags`

---

## 1. 页面定位

展示所有标签，以彩色标签云形式展示。

## 3. 标签规格

| 元素 | 规格 |
|------|------|
| 容器 | 600×280px，圆角 16px，浅灰底 |
| 标签大小 | 热门标签 32px 高，普通 24-28px，小标签 22px |
| 标签颜色 | 随机分配品牌色（紫/绿/橙/粉/蓝/草绿/琥珀） |
| 圆角 | 大标签 8px，小标签 6px |
| 交互 | Hover 加深，点击跳转 `/tags/[slug]` |

## 4. 排序

按文章数降序排列，前 6 个为热门标签（大号展示）。
