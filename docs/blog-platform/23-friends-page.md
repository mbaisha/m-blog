# 23. 友情链接页设计规格

路由：`/friends`

---

## 1. 页面定位

展示友情链接站点，2 列卡片网格。

## 2. 页面结构

```
友情链接
值得关注的朋友和站点

┌────────────────────┐ ┌────────────────────┐
│ (A) Awesome Blog    │ │ (B) Bob's Space     │
│     前端技术·独立开发│ │     产品设计·读书笔记│
│     访问 →          │ │     访问 →          │
├────────────────────┤ ├────────────────────┤
│ (C) Coding Life     │ │ (D) Design Daily    │
│     后端开发·系统设计│ │     UI/UX·设计资源  │
│     访问 →          │ │     访问 →          │
└────────────────────┘ └────────────────────┘

────────────────────────────────────
页脚
```

## 3. 卡片规格

| 元素 | 规格 |
|------|------|
| 卡片尺寸 | 290×56px，圆角 10px |
| 头像 | 40px 圆形，首字母 + 品牌色背景 |
| 站点名 | 14px，font-weight: 500 |
| 描述 | 10px，`#6B7280` |
| 访问链接 | "访问 →"，10px，主色 |

## 4. 数据

```json
GET /api/friends

[
  {
    "name": "Awesome Blog",
    "description": "前端技术·独立开发",
    "url": "https://...",
    "avatarColor": "#EEEDFE"
  }
]
```
