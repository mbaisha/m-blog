# 14. 文章详情页全新设计规格

> 本文档是对 `05-frontend-spec.md` 中 `4.3 文章详情` 的全面升级和替代版本。
> 设计方向：沉浸式阅读 + 内容分发。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 阅读沉浸感 | 正文区最大化，减少视觉干扰，专注内容 |
| 快速导航 | 浮动目录 + 分类导航，随时跳转不打断阅读 |
| 内容分发 | 标签跳转、分类导航、相关文章推荐，自然引导到更多内容 |
| 可信度 | 元信息清晰展示（时间、阅读量、评论数），增强文章可信度 |
| 社区互动 | 评论系统，反灌水规则与文章底部自然衔接 |

## 3. 各区块详细规格

### 3.1 阅读进度条

**位置**：导航栏下方，页面顶部全宽

**行为**：
- 初始宽度 `0%`
- 随文章滚动按比例填充
- 填充色使用主色 `#6366F1`
- 背景色使用浅灰 `#E5E7EB`
- 高度 `3px`，圆角 `1.5px`
- `position: fixed` + `top: 导航栏高度`
- `z-index` 高于正文，低于导航栏
- 移动端同样保留，高度不变

### 3.2 文章 Hero

**布局**：单列垂直排列，居中

**结构**：

```
[ 分类标签 ]    ← 胶囊样式：圆角 4px，主色背景（#EEEDFE），主色文字
[ 文章标题 ]    ← 24-28px，font-weight: 600，行高 1.3
[ 元信息行 ]    ← 13-14px，灰色文字
```

**元信息行内容**：

```text
分类名  ·  作者：Zhu  ·  发布于 2026-06-07  ·  更新于 2026-06-07
预计阅读 8 分钟  ·  1,284 阅读  ·  12 评论
```

- 各项之间用 `·` 分隔
- 如果某字段为空则不显示（如无更新时间则只显示发布时间）
- 阅读量使用千分位格式化：`Intl.NumberFormat().format(count)`

**封面图**：
- 可选，如果存在则置于 Hero 下方
- 宽度 100%，最大高度 400px，圆角 `16px`
- 如果没有封面图，使用品牌色 `#EEEDFE` 浅色渐变占位
- 图片使用 `next/image` 并懒加载

### 3.3 正文区

**尺寸**：
- 桌面端最大宽度 `900px`，左右边距 `24px`
- 正文居中，与右侧栏保持 `24px` 间距

**排版规格**：

| 元素 | 字号 | 字重 | 行高 | 间距 |
|------|------|------|------|------|
| 正文段落 | 16px / 1rem | 400 | 1.75 | 段间距 1.2em |
| H2 标题 | 22px / 1.375rem | 600 | 1.4 | 上边距 2em，下边距 0.5em |
| H3 标题 | 18px / 1.125rem | 600 | 1.4 | 上边距 1.5em，下边距 0.3em |
| H4 标题 | 16px / 1rem | 600 | 1.4 | 上边距 1em |
| 引用块 | 15px | 400 | 1.6 | 左侧 4px 主色竖线 |
| 代码块 | 14px (JetBrains Mono) | 400 | 1.5 | 背景 `#1E293B`（深色） |
| 行内代码 | 14px (JetBrains Mono) | 400 | - | 背景 `#F1F5F9`，圆角 4px |
| 列表项 | 16px | 400 | 1.75 | 缩进 1.5em |
| 图片 | - | - | - | 居中，圆角 12px，懒加载 |
| 表格 | 14px | 400 | 1.5 | 横向滚动容器包裹 |

**提示框组件**（扩展格式）：

三种类型：

| 类型 | 左侧竖线颜色 | 背景色 | 图标 |
|------|-------------|--------|------|
| Tip（提示） | `#22C55E` (green) | `#F0FDF4` | 💡 |
| Info（信息） | `#6366F1` (indigo) | `#EEEDFE` | ℹ️ |
| Warning（注意） | `#F59E0B` (amber) | `#FFFBEB` | ⚠️ |

**Markdown 语法**：

```markdown
:::tip
这是一个提示内容
:::

:::info
这是一个信息说明
:::

:::warning
这是一个注意事项
:::
```

渲染后结构：

```html
<div class="callout callout-tip">
  <div class="callout-icon">💡</div>
  <div class="callout-content">
    <p>这是一个提示内容</p>
  </div>
</div>
```

样式：
- 圆角 `8px`
- 内边距 `16px`
- 左侧 4px 竖线（高度与内容一致）
- 正文区域不喧宾夺主

### 3.4 浮动目录（TOC）

这是最重要的交互创新。目录不占用正文区域，而是作为浮动元素存在。

#### 3.4.1 状态与行为

| 状态 | 表现 |
|------|------|
| **默认** | 页面左侧边缘只显示一个 `28×28px` 的小按钮，半透明 |
| **Hover 按钮** | 按钮背景加深，cursor: pointer |
| **点击按钮** | 展开 140px 宽的浮动目录面板 |
| **展开后** | 面板显示 H1-H3 标题树，当前章节自动高亮（紫色底色） |
| **点击目录项** | 平滑滚动到对应标题位置，**自动收起面板** |
| **点击页面任意位置** | 收起面板 |
| **再次点击按钮** | 收起面板 |
| **移动端** | 按钮置于右下角，点击弹出底部抽屉式目录 |

**设计要点**：
- 按钮 `z-index` 高于正文，低于导航栏
- 面板带浅阴影，半透明白色背景 (`rgba(255,255,255,0.95)`)
- Dark 模式按钮用 `rgba(30,41,59,0.9)` 半透明背景
- 面板高度不超过视口高度的 60%，超出可滚动
- 标题缩进：H2 左侧 0，H3 左侧 12px
- 当前高亮项使用 `#EEEDFE` 背景 + `#6366F1` 文字

#### 3.4.2 目录提取逻辑

- 从渲染后的文章内容中提取 H1 / H2 / H3 标签
- 按文档顺序生成树形结构
- 每个标题项存储：`id`（锚点）、`text`（标题文字）、`level`（1/2/3）
- 通过 `IntersectionObserver` 监听每个标题的可见性
- 当前在视口内的第一个标题标记为高亮
- 如果没有任何标题在视口内（滚动到中间空白区域），保持上一个高亮

#### 3.4.3 滚动行为

- 点击目录项 → `element.scrollIntoView({ behavior: 'smooth', block: 'start' })`
- 导航后会额外偏移 `80px`（避免标题被固定导航栏遮挡）
- 滚动后自动收起目录面板

### 3.5 右侧栏

右侧栏宽度 `220px`，`position: sticky`，跟随页面滚动（`top: 80px`）。

#### 3.5.1 操作区

```
操作
[ 分享 ] [ 收藏 ] [ 复制 ]
```

- 三个按钮横向排列，每个按钮 `42×28px`
- 圆角 `6px`，边框 `1px solid #E5E7EB`
- Hover 时主色填充文字
- 分享：调用 `navigator.share()`（移动端）或复制链接（桌面端）
- 收藏：本地存储或 API 调用，支持切换收藏/取消
- 复制：复制当前文章 URL 到剪贴板，弹出 Toast 提示

#### 3.5.2 分类导航

```
分类导航
前端架构    12 篇
后端开发     8 篇
产品设计     6 篇
读书笔记    15 篇
查看全部 →
```

- 每行：分类名（左对齐）+ 文章数（右对齐）
- 圆角 `6px`，Hover 时背景变为 `#F3F4F6`
- 当前文章所属分类高亮（主色文字 `#6366F1`）
- 点击跳转到 `/categories/[slug]`
- 最多展示 5-6 个热门分类
- 超过部分 +「查看全部」链接到 `/categories`
- 分类排序规则：按文章数降序

### 3.6 底部标签区

**位置**：正文结束后，上一篇/下一篇之前

**结构**：

```
标签
[React] [Next.js] [Tailwind] [TypeScript]
点击标签可跳转到对应标签页
```

**交互**：
- 每个标签都是可点击链接
- 点击跳转到 `/tags/[slug]`
- 标签样式：圆角 `6px`，浅色背景 `#F3F4F6`，Hover 时变为主色背景
- 如果标签数 > 8 个，自动换行
- 不要横向滚动
- 当前文章的标签没有特殊高亮（与列表页区分）
- 提示文字使用辅助色 `#9CA3AF`

### 3.7 上一篇 / 下一篇

**位置**：标签区之后，相关文章之前

**结构**：

```
← 上一篇：从零搭建一个现代个人博客平台
下一篇：前端性能优化实践 →
```

- 左右分两列，各占 50%
- 圆角 `8px`，边框 `1px solid #E5E7EB`
- Hover 时背景变为 `#F9FAFB`
- 如果某一侧无文章，显示为灰色占位状态：`← 已是第一篇`
- 点击跳转到 `/articles/[slug]`
- 设计要克制，不要做得像大 Banner，不打断阅读结束后的自然退出

### 3.8 相关文章

**位置**：上一篇/下一篇之后

**结构**：

```
相关文章

[ 卡片 ]  [ 卡片 ]  [ 卡片 ]
```

- 3 篇小卡片横向排列
- 每张卡片包含：标题 + 分类标签 + 时间
- 圆角 `10px`，边框 `1px solid #E5E7EB`
- Hover 时轻微上浮 `2px`
- 不展示封面图（保持简洁）
- 推荐策略：同分类 > 同标签 > 最新发布
- 如果不足 3 篇，显示已有数量，不要占位

### 3.9 评论区

**位置**：相关文章之后

**流程**（保持原有反灌水规则）：

```
用户填写评论
  → 前端基础校验（内容非空、邮箱格式）
  → 获取验证码（图形验证码 / 无感验证）
  → 提交评论 POST /api/comments
  → 后端验证码校验
  → 后端 IP 频率限制（同 IP 60 秒内最多 1 次）
  → 后端内容长度校验（2-2000 字符）
  → 敏感词过滤
  → 链接限制（最多 2 个链接）
  → 重复内容检测（同文章、同 IP、60 分钟内相似内容拒绝）
  → 写入数据库（status = 'pending'）
  → 返回提交成功
  → 前台展示审核提示
```

**设计结构**：

```
评论（12）

[ 输入框：写评论... 昵称 · 邮箱 · 验证码 ]
[ 提交按钮 ]

提示：评论提交后将进入审核，首次评论或包含链接的评论可能需要稍后显示。

头像  用户名  时间
      评论内容
      [回复]

头像  用户名  时间
      评论内容
      [回复]
      头像  回复：@用户名
            回复内容

加载更多 →
```

**设计要求**：
- 输入框 `border-radius: 8px`，背景 `#F9FAFB`
- 提交按钮使用主色
- 评论列表中头像使用首字母圆形头像（`#EEEDFE` 背景 + 主色文字）
- 评论按时间倒序排列
- 分页：默认 10 条，点击"加载更多"加载下 10 条
- 管理员可置顶评论（显示"置顶"标签）
- 审核中的评论不展示
- 回复列表默认折叠，点击展开

## 4. 移动端适配

### 4.1 页面结构（< 768px）

```
导航（汉堡菜单）
  ↓
阅读进度条（3px）
  ↓
文章 Hero（单列）
  分类标签
  标题
  元信息行
  封面图（全宽）
  ↓
正文（单列，左右边距 16px）
  ↓
标签区
  ↓
上一篇 / 下一篇
  ↓
相关文章（单列，纵向排列）
  ↓
评论区
  ↓
页脚
```

### 4.2 特殊适配

| 元素 | 移动端行为 |
|------|-----------|
| 浮动目录 | 按钮移到右下角 `bottom: 80px; right: 16px`；点击弹出底部抽屉面板（底部升起，覆盖 50% 视口高度，圆角 16px 顶部） |
| 右侧栏 | 全部移到正文之后、标签区之前，折叠为两个小卡片横向排列 |
| 正文 | 边距 `16px`，字号保持 `16px` 不缩小 |
| 代码块 | 可横向滚动 |
| 表格 | 横向滚动容器包裹 |
| 上一篇/下一篇 | 纵向排列，各占 100% 宽度 |
| 相关文章 | 单列，纵向排列 |
| 评论区 | 单列，表单输入框全宽 |
| 图片 | 全宽，不溢出 |
| 文件大小 | 首屏 JS bundle < 200KB |
| 触控 | 所有可点击区域 ≥ 44×44px |

### 4.3 平板端（768px - 1023px）

- 最大内容宽度：`96%`
- 布局保持双栏，但右侧栏宽度缩小为 `180px`
- 正文区最大宽度 = 内容区宽度 - 右侧栏宽度 - 间距
- 目录按钮位置不变（左侧边缘）
- 触控区域 ≥ 44×44px

## 6. 交互与动效规范

| 操作 | 动效 | 时长 |
|------|------|------|
| 卡片 Hover | 上浮 2-4px + 边框加深 | 200ms ease-out |
| 按钮 Hover | 背景变深 + 文字变主色 | 150ms |
| 目录面板展开/收起 | 淡入淡出 + 水平滑动 | 200ms |
| 阅读进度条 | 线性填充 | 随滚动即时更新 |
| 标签 Hover | 背景变为主色浅色 (`#EEEDFE`) | 150ms |
| 点击跳转目录 | 平滑滚动 | 300ms |
| Toast 提示 | 底部升起 + 3s 后淡出 | 300ms in, 500ms out |
| 分类 Hover | 背景变 `#F3F4F6` | 150ms |
| 骨架屏 | 渐变闪烁 | 1.5s 循环 |

**尊重 `prefers-reduced-motion`**：所有动效在该偏好启用时降级为即时切换。

## 9. 无障碍 (a11y)

| 要求 | 实现方式 |
|------|---------|
| 键盘导航 | 目录项可 Tab 聚焦并 Enter 跳转 |
| 屏幕阅读器 | 浮动目录面板 `role="navigation"` + `aria-label="文章目录"` |
| 焦点管理 | 展开目录时将焦点移入面板，关闭时回到按钮 |
| 对比度 | 正文 ≥ 4.5:1，辅助文字 ≥ 3:1 |
| 阅读进度条 | `role="progressbar"` + `aria-valuenow` |
| 评论表单 | 各输入框均有 `<label>` 或 `aria-label` |

## 10. 性能目标

| 指标 | 目标 |

- WebP 格式优先
