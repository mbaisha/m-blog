# 22. 留言板设计规格

路由：`/message`

---

## 1. 页面定位

访客留言交流的页面。包含留言表单和留言列表。

## 2. 页面结构

```
留言板
有什么想说的，欢迎留言

┌─ 留言表单 ─────────────────────────────────┐
│ [昵称        ] [邮箱（选填）]               │
│                                            │
│ [在这里写下你想说的话...]                    │
│                                            │
│ [验证码] [A7K2] [输入验证码]    [提交留言]  │
└────────────────────────────────────────────┘

留言（8）

M  小明                    2026-06-07 14:30
    写得很好，学到了不少东西！加油！
A  Alex                    2026-06-06 09:15
    能分享一下你的开发环境配置吗？
L  LittleStar              2026-06-05 20:42
    关注你很久了，每篇文章都很有深度。

加载更多留言 →

────────────────────────────────────
页脚
```

## 3. 规格

### 表单

| 元素 | 规格 |
|------|------|
| 昵称 | 必填，130×28px |
| 邮箱 | 选填，200×28px |
| 内容 | 560×36px textarea |
| 验证码 | 图形验证码显示 + 输入框 |
| 提交按钮 | 深色底 `#1F2937`，白色文字，100×28px |

### 留言列表

| 元素 | 规格 |
|------|------|
| 头像 | 28px 圆形，首字母 + 品牌色背景 |
| 用户名 | 12px，font-weight: 500 |
| 时间 | 10px，`#9CA3AF` |
| 内容 | 12px，`#6B7280` |
| 分页 | "加载更多留言 →"，主色文字 |

### 反灌水规则

与文章评论区一致：验证码、IP 限频、内容过滤、审核后可见。
