# 26. 404 页面设计规格

路由：`*`（未匹配路由）

---

## 1. 页面定位

友好的错误提示页，引导访客回到正常页面。

## 2. 页面结构

```
          404

       页面未找到
  你访问的页面不存在或已被移除

     [返回首页]  查看文章 →

   你可能想找
 ┌──────────┐ ┌──────────┐ ┌──────────┐
 │ 最新文章  │ │ 热门标签  │ │ 全部分类  │
 │ 看看更新  │ │ React...│ │ 浏览内容  │
 └──────────┘ └──────────┘ └──────────┘

────────────────────────────────────
页脚
```

## 3. 规格

| 元素 | 说明 |
|------|------|
| 404 数字 | 64px，font-weight: 400，`#EEEDFE`（淡紫色，不刺眼） |
| 标题 | "页面未找到"，18px，font-weight: 500 |
| 描述 | "你访问的页面不存在或已被移除"，13px，`#6B7280` |
| 返回首页 | 深色按钮 `#1F2937`，100×34px |
| 查看文章 | 文字链接，主色 |
| 建议卡片 | 3 列，185×44px，白底灰边框，11px 文字 |

## 4. 建议卡片

| 卡片 | 内容 | 链接 |
|------|------|------|
| 最新文章 | 标题 + "看看最近更新了什么" | `/articles` |
| 热门标签 | 标题 + "React · Next.js · Go" | `/tags` |
| 全部分类 | 标题 + "浏览所有内容分类" | `/categories` |
