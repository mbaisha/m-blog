# 00R. 响应式设计规范（全端适配）

> 统一规范所有页面在桌面端、平板、手机端的适配规则。
> 所有设计文档引用的响应式行为以此文档为准。

---

## 1. 断点定义

| 端 | 断点 | 内容容器 | 边距 |
|----|------|---------|------|
| 桌面端 | ≥ 1024px | max-width: 1200px | 左右 24px |
| 平板 | 768px ~ 1023px | 96% | 左右 20px |
| 手机 | < 768px | 100% | 左右 16px |

---

## 3. 首页适配

### 桌面端（≥ 1024px）

完整布局：标题行 → 导航栏 → Hero → 精选 3 列 → 最新列表 → 项目 2 列 → 页脚

### 平板（768px ~ 1023px）

| 模块 | 适配 |
|------|------|
| Hero | 右侧统计方块变为 2×2 排列（缩小至 44px）|
| 精选 | 3 列不变，卡片尺寸自适应压缩 |
| 最新 | 列表不变，缩略图缩小至 44px |
| 项目 | 2 列不变 |

### 手机（< 768px）

```
导航抽屉
  ↓
Hero（单列）                    ← 右侧统计方块变为 4 个水平排列
  ↓
精选文章（单列卡片，竖向排列）    ← 卡片变全宽
  ↓
最新文章（单列列表）
  ↓
项目（单列，竖向排列）
  ↓
页脚（垂直排列链接）
```

| 模块 | 适配 |
|------|------|
| Hero | 文字全宽，统计方块 4 个水平排列，字号缩小 |
| 精选 | 3 列变为 1 列，卡片全宽 |
| 最新 | 单列列表，缩略图缩小 |
| 项目 | 2 列变为 1 列，竖向排列 |

## 4. 列表页适配

### 桌面端（≥ 1024px）

| 侧边栏状态 | 卡片列数 |
|-----------|---------|
| 展开（150px） | 2 列 |
| 收起（28px 竖条） | 3 列 |

### 平板（768px ~ 1023px）

| 侧边栏状态 | 卡片列数 |
|-----------|---------|
| 默认收起 | 2 列 |
| 展开 | 1 列（太窄时不推荐展开） |

- 侧边栏默认收起，仅保留 28px 竖条
- 点击竖条展开时，卡片变为 1 列
- 搜索条宽度自适应

### 手机（< 768px）

| 侧边栏 | 卡片列数 |
|--------|---------|
| 完全隐藏 | 1 列 |

- 右侧栏完全隐藏，改为底部浮动「筛选」按钮
- 点击筛选按钮弹出底部抽屉：分类列表 + 标签云
- 卡片单列，全宽
- 搜索条：输入框可折叠，默认只显示 🔍 图标
- 分页：改为「加载更多」按钮
- 列表模式：单列，行宽全屏

## 5. 详情页适配

### 桌面端（≥ 1024px）

```
┌──── TOC ────┬──── 正文（900px）────┬──── 侧栏 220px ──┐
│  浮动按钮   │                      │  操作              │
│  (28x28)    │  Markdown 内容       │  分类导航          │
│  点击展开   │                      │                   │
│  140px 面板 │  底部：标签           │                   │
│             │  上一篇/下一篇        │                   │
│             │  相关文章             │                   │
│             │  评论区               │                   │
└─────────────┴──────────────────────┴───────────────────┘
```

### 平板（768px ~ 1023px）

```
┌──── 正文 ───────────────────────┬──── 侧栏 180px ───┐
│                                │  操作              │
│  Markdown 内容                 │  分类导航          │
│                                │                   │
│  浮动 TOC 按钮在左侧            │                   │
│                                │                   │
│  底部：标签                     │                   │
│  上一篇/下一篇                  │                   │
│  相关文章（2 列）               │                   │
│  评论区                        │                   │
└────────────────────────────────┴───────────────────┘
```

- 正文缩小，侧栏缩小至 180px
- TOC 按钮位置不变
- 相关文章变为 2 列

### 手机（< 768px）

```
导航
  ↓
正文（单列，边距 16px）
  ↓
标签区
  ↓
上一篇 / 下一篇
  ↓
相关文章（单列）
  ↓
评论区
  ↓
页脚

（浮动 TOC 按钮在右下角）
（右侧栏内容移到正文后、标签前，折叠为两个小卡片）
```

- TOC 按钮移到右下角 `bottom: 80px; right: 16px`
- 点击弹出底部抽屉式目录（覆盖 50% 视口，顶部圆角 16px）
- 右侧栏操作和分类导航移到正文后，折叠为横向两个小卡片
- 相关文章单列
- 评论区单列

## 16. 通用响应式规则

### 图片

```css
img {
  max-width: 100%;
  height: auto;
}
```

### 表格

```css
.table-wrapper {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
}
```

### 代码块

```css
pre {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  font-size: 14px;
}
```

### 触控目标

手机端所有可点击区域 ≥ 44×44px。

### 字体缩放

| 元素 | 桌面 | 手机 |
|------|------|------|
| 页面大标题 | 20px | 18px |
| Hero 标题 | 30px | 24px |
| 卡片标题 | 13px | 12px |
| 正文 | 16px | 16px（不缩小）|
| 元信息 | 10px | 9px |
