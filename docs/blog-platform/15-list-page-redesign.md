# 15. 文章列表页全新设计规格

> 本文档是对 `05-frontend-spec.md` 中 `4.2 文章列表` 的全面升级和替代版本。
> 设计方向：内容检索 + 内容发现，简洁大气。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 高效检索 | 搜索 + 分类筛选 + 标签筛选 + 排序，快速找到目标文章 |
| 内容发现 | 侧边栏分类导航 + 标签云，引导用户探索更多内容 |
| 双视图模式 | 卡片网格（默认，视觉化）+ 列表（紧凑，适合扫描） |
| 自适应布局 | 侧边栏可折叠，卡片网格自动调整列数 |
| 沉浸感 | 干净留白，不突兀的筛选工具，内容始终处于视觉中心 |

## 3. 各区块详细规格

### 3.1 页面 Hero

极简风格，没有多余装饰：

| 元素 | 规格 |
|------|------|
| 大标题 | "文章"，字号 20-22px，font-weight: 500 |
| 描述 | 字号 12px，颜色 `#6B7280` |
| 统计 | "共 42 篇文章 · 8 个分类"，字号 11px，颜色 `#9CA3AF` |

### 3.2 搜索条

**位置**：Hero 下方，页面主内容区上方

**布局**：一行排列

```
┌─────────────────────────────────────────────────────────┬────┬────┐
│ 🔍 搜索文章标题或内容...   全部分类 ▼   排序 ▼   [ 搜索 ] │ [▦]│[☰]│
└─────────────────────────────────────────────────────────┴────┴────┘
```

| 控件 | 说明 |
|------|------|
| 搜索输入框 | 宽度 150px，圆角 6px，带 🔍 图标 |
| 全部分类 ▼ | 下拉选择分类，支持多选（后续迭代），选中后标签显示在结果行 |
| 排序 ▼ | 下拉：最新发布 / 最多阅读 / 最多评论 / 最近更新 |
| [搜索] 按钮 | 主色填充 `#6366F1`，白色文字，圆角 6px，点击执行搜索 |
| [▦] / [☰] | 卡片/列表视图切换按钮 |

**交互**：
- 输入关键词 + 回车 → 搜索
- 输入关键词 + 点击 [搜索] → 搜索
- 选择分类 → 自动筛选，搜索范围限定
- 选择排序 → 重新排序结果

**搜索条 `position: sticky`**，跟随页面滚动固定，方便随时调整筛选条件。

### 3.3 右侧栏（可折叠）

**宽度**：展开时 150px，收起时 28px

**展开态**：

```
┌─ 右侧栏 150px ──────────────────┐

│  ────────                         │
│  全部分类                   42    │  ← 当前选中，淡紫底
│  前端架构                   12    │
│  ├─ React                        │  ← 二级分类，缩进
│  ├─ Vue                          │
│  └─ Angular                      │
│  后端开发                    8    │
│  ├─ Go                           │
│  └─ Java                         │
│  产品设计                    6    │
│  ────────                         │
│  标签云                           │
│  [React]  [Next.js]              │  ← 彩色标签
│  [Go]  [Docker]                  │
│  [TypeScript]  [AI]  [设计]      │
└──────────────────────────────────┘
  ▲ 右上角 ◀ 收起按钮
```

**收起态**（28px 竖条）：

```
┌──┐
│▶ │  ← 展开按钮
│  │
│分│  ← 竖排文字
│类│
│与│
│标│
│签│
└──┘
```

**交互**：
- 点击 ◀ → 侧边栏收起，卡片网格从 2 列变为 3 列
- 点击竖条上的 ▶ → 侧边栏展开，恢复 2 列
- 动画 200ms ease-out
- 收起时当前分类/标签筛选状态不变

**`position: sticky`** 跟随滚动。

#### 3.3.1 分类树

| 元素 | 规格 |
|------|------|
| 分类标题 | "分类"，11px，font-weight: 500，`#374151` |

#### 3.3.2 标签云

**位置**：分类列表下方，用 0.5px 分隔线隔开

**标签样式**：

- 点击标签 → 按标签筛选文章，与分类筛选可叠加
- Hover 时背景加深

### 3.5 卡片网格（默认视图）

#### 3.5.1 自适应列数

| 侧边栏状态 | 列数 | 每张卡宽度 |
|-----------|------|-----------|
| 展开（150px） | 2 列 | ~480px |
| 收起（28px） | 3 列 | ~370px |
| 平板（768-1023px） | 2 列 | 自动 |
| 手机（<768px） | 1 列 | 自动 |

**实现**：

```css
.grid-container {
  display: grid;
  gap: 20px;
  grid-template-columns: repeat(2, 1fr);
}

.grid-container.sidebar-hidden {
  grid-template-columns: repeat(3, 1fr);
}

/* 平板 */
@media (max-width: 1023px) {
  .grid-container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 手机 */
@media (max-width: 767px) {
  .grid-container {
    grid-template-columns: 1fr;
  }
}
```

所有卡片**宽高严格一致**，使用 `aspect-ratio: 4/3` 或固定高度 `168px`。

#### 3.5.2 卡片设计

```
┌──────────── 185-480px ────────────┐
│                                    │
│           封面图（约 50% 高度）       │ ← 品牌色铺底或真实图片
│  [分类徽章]                         │ ← 左上角，半透明白底
│                                    │
├────────────────────────────────────┤
│  标题（2 行，超出省略）               │ ← 12-13px，font-weight: 500
│  分类 · 日期 · 📍阅读 · 📖时长       │ ← 10px，灰色
│  [标签1] [标签2]                    │ ← 灰底小胶囊
└────────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 卡片圆角 | 10-12px |
| 边框 | 0.5px `#E5E7EB` |
| 阴影 | `drop-shadow(0 2px 6px rgba(0,0,0,0.04))` |
| 封面图高度 | 卡片总高度的 50%（约 84px/168px） |
| 封面图颜色 | 每个分类一种品牌色浅色铺底（无图时使用） |
| 分类徽章 | 左上角，白底 `opacity: 0.88`，9px，圆角 4px |
| 标题 | 13px，font-weight: 500，最多 2 行，超出省略 |
| 元信息行 | 10px，`#6B7280`：分类名 · 日期 · 📍阅读数 · 📖阅读时长 |
| 标签 | 灰底 `#F3F4F6`，8px，`#6B7280`，圆角 3px，可点击 |
| Hover | 上浮 2px + 阴影加深，200ms |

**封面图颜色映射**（后台可配置）：

| 分类 | 封面色 |
|------|--------|
| 前端架构 | `#EEEDFE`（紫色调） |
| 后端开发 | `#E1F5EE`（绿色调） |
| 产品设计 | `#FAECE7`（暖色调） |
| 读书笔记 | `#FBEAF0`（粉色） |
| AI 实践 | `#EAF3DE`（草绿） |
| 工具效率 | `#FAEEDA`（琥珀） |

如果文章有真实封面图，优先显示真实图片；没有时使用分类品牌色铺底。

**阅读时长计算**：文章字数 / 300 ≈ 分钟数，不足 1 分钟显示 "1 分钟"

## 6. 关键交互详解

### 6.1 搜索流程

```text
用户输入关键词 + 回车/点击搜索
  → URL 更新: ?q=关键词&category=xxx&sort=xxx
  → 显示骨架屏
  → API 请求 GET /api/articles?q=关键词&category=xxx&sort=xxx&page=1
  → 返回结果
  → 隐藏骨架屏
  → 渲染卡片/列表
  → 结果行显示: "关键词" 的搜索结果 · 12 篇文章
  → 关键词在标题/摘要中高亮（紫色 <mark> 背景）
```

### 6.2 分类筛选流程

```text
用户点击侧边栏「前端架构」
  → 侧边栏中「前端架构」高亮为淡紫底
  → 搜索条中「全部分类 ▼」→「前端架构」
  → URL 更新: ?category=frontend
  → 结果行显示: 前端架构 · 12 篇文章
  → 卡片网格更新
```

### 6.3 标签筛选流程

```text
用户点击标签云中的「React」
  → 标签「React」背景加深（选中态）
  → 结果行显示: 前端架构 · 8 篇文章（React · 4）
  → URL 更新: ?category=frontend&tag=React
  → 卡片网格只显示带 React 标签的文章
  → 再次点击取消选中
```

### 6.4 侧边栏折叠流程

```text
用户点击 ◀
  → 右侧栏从 150px 收缩到 28px
  → 搜索条宽度增加
  → 卡片网格从 grid-cols-2 变为 grid-cols-3
  → 卡片自动计算新尺寸
  → 当前筛选状态保持不变

用户点击 ▶（竖条上）
  → 右侧栏从 28px 展开到 150px
  → 搜索条宽度恢复
  → 卡片网格从 grid-cols-3 变为 grid-cols-2
```

### 6.5 视图切换流程

```text
用户点击 [▦]（当前在列表模式）
  → 列表淡出（100ms）
  → 卡片淡入（100ms）
  → 按钮状态切换：[▦] 高亮，[☰] 变灰

用户点击 [☰]（当前在卡片模式）
  → 卡片淡出
  → 列表淡入
  → 按钮状态切换：[☰] 高亮，[▦] 变灰
```

## 8. SEO 与 URL 参数

### 8.1 URL 参数规范

所有筛选状态通过 URL 参数持久化：

```
/articles?q=react&category=frontend&tag=React&sort=popular&page=2&view=grid
```

| 参数 | 说明 | 示例 |
|------|------|------|
| `q` | 搜索关键词 | `q=react` |
| `category` | 分类 slug | `category=frontend` |
| `subcategory` | 二级分类 | `subcategory=react` |
| `tag` | 标签 | `tag=React` |
| `sort` | 排序方式 | `sort=popular` |
| `page` | 页码 | `page=2` |
| `view` | 视图模式 | `view=grid` 或 `view=list` |

### 8.2 页面 SEO

```html
<title>文章 | 博客名</title>
<meta name="description" content="记录技术实践、产品思考、读书笔记与项目复盘" />
<link rel="canonical" href="https://example.com/articles" />

<!-- 如果按分类筛选 -->
<meta name="robots" content="noindex, follow" />
```
