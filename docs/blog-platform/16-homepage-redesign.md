# 16. 首页全新设计规格

> 本文档是对 `05-frontend-spec.md` 中 `4.1 首页` 的全面升级和替代版本。
> 设计方向：个人品牌门户 + 内容精选入口，精致现代。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 个人品牌展示 | 第一眼知道你是谁、擅长什么、有什么值得读 |
| 内容精选入口 | 精选 + 最新 + 热门标签，引导发现内容 |
| 精致美观 | 克制的配色、细腻的圆角、舒适留白 |
| 现代化交互 | 悬停搜索、Dark Mode、滚动动画、骨架屏 |
| 后台可配置 | 导航菜单项从后台 API 获取 |

## 3. 各区块详细规格

### 3.1 顶部标题行

| 元素 | 规格 |
|------|------|
| 网站标题 | "Zhu's Blog"，16px，font-weight: 550，letter-spacing: 1px |
| 位置 | 页面最顶部，左边距 60px |
| 搜索图标 | 24×24px 灰色圆角按钮，最右侧，悬停/点击展开为搜索框 |

**搜索交互**：

```text
默认状态：标题行最右侧 🔍 灰色小按钮（#F3F4F6 背景）

鼠标悬停 / 点击：
  → 按钮向右展开为搜索输入框（宽 230px，高 24px）
  → 紫边框 1.5px（#6366F1），圆角 8px
  → placeholder："🔍 输入关键词搜索..."
  → 右侧紫色小字"回车"

回车 / 点击搜索：
  → 跳转到 /search?q=关键词

失焦：
  → 自动收起为图标
```

### 3.2 导航栏

**位置**：标题行下方，圆角胶囊条

**规格**：
- 宽度：600px，居中
- 高度：44px
- 圆角：10px
- 背景：`#F8FAFC`
- 边框：0.5px `#E5E7EB`

**导航项**：
- 当前项：紫底 `#EEEDFE` + 主色文字（如「首页」）
- 其他项：灰色文字 `#6B7280`
- 菜单项从后台 API `GET /api/navigation` 获取，后台可配置顺序和显示/隐藏
- 默认包含：首页 / 文章 / 项目 / 关于 / 留言 / 友链
- 右侧保留 🔍 搜索图标和 🌙 Dark Mode 切换按钮

**搜索图标**在导航栏中仅作为快捷入口（功能同标题行的搜索按钮，两者触发同一个搜索框，也可以独立使用导航栏的搜索）。

## 4. 新增交互功能

### 4.1 Dark Mode 切换

导航栏右侧 🌙 按钮：
- 默认跟随系统 `prefers-color-scheme`
- 点击可在 light/dark 间手动切换
- 状态存入 localStorage，刷新保持
- Dark 模式色值表详见 `14-detail-page-redesign.md`

### 4.2 回到顶部按钮

- 右下角浮动，距底部 40px，距右侧 40px
- 滚动超过 400px 后出现（淡入 200ms）
- 点击平滑滚动回顶部
- 24×24px 圆形，`#F3F4F6` 背景，↑ 箭头
- 回到顶部后自动淡出

### 4.3 滚动渐入动画

- 每个模块进入视口时触发
- 动画：translateY(20px) → translateY(0) + opacity(0→1)
- 持续时间 400ms，ease-out
- 同一行的子元素依次延迟 100ms
- 使用 `IntersectionObserver`，只执行一次
- 尊重 `prefers-reduced-motion`

### 4.4 加载骨架屏

首屏加载时显示骨架脉冲动画：

```css
.skeleton {
  background: linear-gradient(90deg, #F3F4F6 25%, #E5E7EB 50%, #F3F4F6 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

- Hero 骨架：灰色矩形，尺寸与真实 Hero 一致
- 卡片骨架：3 个灰色矩形，尺寸与真实卡片一致
- 列表骨架：3 个灰色矩形，尺寸与真实列表项一致

### 4.5 邮件订阅（可选模块）

位于页脚上方：

```
订阅更新
┌──────────────────────────────────────┐
│  输入邮箱地址...              [ 订阅 ] │
└──────────────────────────────────────┘
不错过每一篇新文章 · 每周一封，随时退订
```

- 输入框圆角 8px，边框 `#E5E7EB`
- 订阅按钮主色填充
- 调用 `POST /api/subscribe`
- 可后台配置开启/关闭
