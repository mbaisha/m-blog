# 12. 开发阶段、任务拆分与验收标准

## 1. 阶段划分

### Phase 0：项目初始化

目标：

- 建立仓库结构。
- 初始化前端、后台、后端。
- 配置 PostgreSQL。
- 配置环境变量。
- 配置基础 CI / Docker。

---

### Phase 1：后端基础

目标：

- 搭建 ASP.NET Core API。
- 连接 PostgreSQL。
- 实现 EF Core。
- 实现 JWT 登录。
- 实现统一响应。
- 实现异常处理。
- 实现日志。

---

### Phase 2：后台管理基础

目标：

- 搭建 Vue3 管理后台。
- 实现登录页。
- 实现路由守卫。
- 实现仪表盘。
- 实现基础布局。

---

### Phase 3：内容管理

目标：

- 实现文章管理。
- 实现 Markdown 编辑器。
- 实现分类标签。
- 实现图片上传。
- 实现文章发布。

---

### Phase 4：前台博客

目标：

- 实现首页。
- 实现文章列表。
- 实现文章详情。
- 实现分类、标签、归档。
- 实现 SEO。
- 实现响应式布局。

---

### Phase 5：评论与反灌水

目标：

- 实现验证码。
- 实现评论提交。
- 实现评论审核。
- 实现频率限制。
- 实现敏感词过滤。
- 实现后台评论管理。

---

### Phase 6：个人品牌模块

目标：

- 实现关于我。
- 实现项目展示。
- 实现友情链接。
- 实现个人页面配置。
- 实现媒体库。

---

### Phase 7：自定义页面与站点配置

目标：

- 实现自定义页面创建 / 编辑 / 发布。
- 实现导航菜单管理。
- 实现页脚区块管理。
- 实现站点配置（主色调、站点名称等）。
- 实现首页与内页模块布局配置。

---

### Phase 8：访问统计与访客记录

目标：

- 实现访问记录上报接口。
- 实现访问记录列表与详情。
- 实现阅读数去重逻辑。
- 实现自动清理定时任务。
- 实现趋势图表。

---

### Phase 9：视觉升级、SEO、性能、部署

目标：

- 适配三端响应式设计。
- 实现主色调自动应用。
- 实现移动端导航折叠。
- 实现 Sitemap。
- 实现 Robots。
- 优化首屏性能。
- 配置缓存。
- 配置 Docker Compose。
- 完成部署。

---

## 3. 验收标准

### 3.1 后端验收

- API 可启动。
- 数据库可连接。
- 登录可用。
- 后台接口受保护。
- 所有接口响应结构统一。
- 所有异常统一处理。
- 评论接口有验证。
- 上传接口有安全校验。

---

### 3.2 前台验收

- 首页可访问。
- 文章可访问。
- 分类可访问。
- 标签可访问。
- 搜索可用。
- 评论可提交。
- SEO Meta 正常。
- 响应式适配正常（桌面 / 平板 / 手机三端页面无错乱）。
- 自定义页面可访问。
- 导航栏菜单正常（后台修改后前台实时更新）。
- 页脚信息正常展示（版权、备案、社交链接等）。
- 文章和自定义页面展示阅读数。
- 页面加载动画 / 骨架屏正常。

---

### 3.3 后台验收

- 管理员可登录。
- 文章可管理。
- 分类标签可管理。
- 评论可审核。
- 媒体可上传。
- 个人页面可配置。
- 项目可管理。
- SEO 可配置。
- 自定义页面可创建 / 编辑 / 发布 / 删除。
- 导航栏可管理（增删改查、排序、可见）。
- 页脚可管理（每个区块的启停、内容编辑）。
- 首页模块布局可配置（模块启用、排序、数据源）。
- 主题色可修改且前台生效。
- 访问记录可查看和筛选。
- 访问记录清理功能正常。

---

## 4. 发布标准

发布前必须完成：

- 所有 P0 功能完成。
- 所有 P0 Bug 修复。
- 后台登录正常。
- 前台 SEO 正常。
- 评论反灌水正常。
- 上传安全正常。
- 数据库迁移正常。
- 响应式三端适配正常。
- 自定义页面正常。
- 导航栏和页脚正常。
- 主题色正常。
- 访问统计和清理正常。
- Docker Compose 可启动。
- 备份策略可用。
- 日志可查看。
