# 07. 评论与反灌水设计

## 1. 目标

评论系统必须支持正常用户互动，同时防止灌水、刷评论、广告提交和机器人攻击。

核心原则：

- 正常用户体验尽量简单。
- 机器人提交成本尽量高。
- 后端校验永远优先于前端校验。
- 所有评论默认不可信。
- 所有提交入口都需要验证。

---

## 2. 评论提交链路

```text
用户打开文章
 ↓
填写评论
 ↓
前端基础校验
 ↓
获取验证码
 ↓
提交评论 API
 ↓
后端验证码校验
 ↓
后端 IP 频率限制
 ↓
后端内容长度校验
 ↓
后端敏感词过滤
 ↓
后端链接限制
 ↓
后端重复内容检测
 ↓
写入数据库
 ↓
返回提交结果
 ↓
后台审核后可见
```

---

## 3. 验证码策略

### 3.1 第一阶段

建议使用：

- 图形验证码。
- IP 频率限制。
- 内容过滤。
- 审核机制。

### 3.2 后续增强

可升级为：

- 滑动验证码。
- 行为验证。
- 第三方验证码。
- 设备指纹。
- 风险评分。

---

## 4. 频率限制

### 4.1 评论频率

| 规则 | 限制 |
|---|---|
| 同一 IP 每分钟 | 最多 1 次 |
| 同一 IP 每 10 分钟 | 最多 3 次 |
| 同一文章每 5 分钟 | 最多 1 次 |
| 同一用户每小时 | 最多 5 次 |
| 连续失败 5 次 | 临时限制 10 分钟 |

### 4.2 验证码频率

| 规则 | 限制 |
|---|---|
| 同一 IP 每分钟获取验证码 | 最多 5 次 |
| 验证码有效期 | 5 分钟 |
| 验证码使用次数 | 1 次 |
| 验证码错误次数 | 3 次后失效 |

---

## 5. 内容校验

### 5.1 基础校验

| 字段 | 规则 |
|---|---|
| nickname | 1-64 字符 |
| email | 合法邮箱，可选 |
| website | 合法 URL，可选 |
| content | 5-1000 字符 |
| articleId | 必须存在且已发布 |

### 5.2 内容拒绝规则

以下内容直接拒绝：

- 空内容。
- 纯空格。
- 纯表情。
- 纯链接。
- 大量重复字符。
- 明显脚本内容。
- 明显恶意 HTML。
- 敏感词命中。
- 重复评论。

### 5.3 进入审核规则

以下内容进入审核：

- 包含链接。
- 包含邮箱。
- 包含手机号。
- 包含疑似广告词。
- 包含敏感词但未达到拒绝标准。
- 新用户首次评论。
- 同一 IP 短时间多次提交。

---

## 6. 链接限制

### 6.1 默认策略

- 评论默认不允许包含链接。
- 如果允许，最多 1 个链接。
- 所有链接自动添加 `rel="nofollow"`。
- 所有链接必须使用 `https` 或 `http`。
- 禁止 `javascript:`、`data:` 等协议。

### 6.2 高风险域名

以下域名进入审核或拒绝：

- 短链接服务。
- 博彩域名。
- 成人域名。
- 恶意下载域名。
- 已知垃圾站域名。

---

## 7. 重复内容检测

### 7.1 检测维度

- 同一 IP。
- 同一文章。
- 同一昵称。
- 同一内容。
- 同一时间段。

### 7.2 规则

```text
同一 IP + 同一文章 + 5 分钟内 + 内容相似度 > 90%
```

命中后：

- 第一次进入审核。
- 第二次拒绝。
- 后续临时限制。

---

## 8. 后端限流实现建议

### 8.1 使用 ASP.NET Core Rate Limiting

适合：

- IP 限流。
- 接口级限流。
- 验证码接口限流。

### 8.2 自定义限流服务

适合：

- 评论业务限流。
- 同一文章限流。
- 同一 IP + 文章组合限流。

---

## 9. 评论状态流转

```text
提交
 ↓
pending
 ↓
approved / rejected / hidden / spam
```

### 状态说明

| 状态 | 说明 |
|---|---|
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已拒绝 |
| hidden | 已隐藏 |
| spam | 垃圾评论 |

---

## 10. 前台交互

### 10.1 提交前

- 校验昵称。
- 校验邮箱格式。
- 校验评论内容长度。
- 显示验证码。
- 显示提交按钮 loading。

### 10.2 提交后

- 成功：提示“评论已提交，等待审核”。
- 失败：提示具体原因。
- 验证码错误：刷新验证码。
- 频率限制：提示稍后再试。

---

## 11. 后台管理

### 11.1 评论列表

需要展示：

- 昵称。
- 邮箱。
- 评论内容。
- 来源文章。
- IP 摘要。
- 提交时间。
- 状态。
- 是否垃圾评论。

### 11.2 操作

- 审核通过。
- 拒绝。
- 删除。
- 标记垃圾评论。
- 批量审核。
- 批量删除。

---

## 12. 验收标准

- 未通过验证码不能提交评论。
- 同一 IP 高频提交会被限制。
- 空评论不能提交。
- 纯链接评论不能提交。
- 重复评论会被限制。
- 包含敏感词评论进入审核。
- 包含链接评论进入审核。
- 后台可以审核、拒绝、删除评论。
- 前台只展示已审核评论。
- 评论接口不会泄露 IP 明文。
