# 05. Next.js 前台前端规格

## 1. 目标

前台博客端面向访客，核心目标是：

- 高颜值。
- SEO 友好。
- 阅读体验优秀。
- 首屏性能良好。
- 响应式适配移动端。
- 支持评论提交。
- 支持文章、分类、标签、归档、搜索、关于我、项目展示、友情链接、留言板。

## 4. 页面规格

### 4.0 2026 前台视觉与布局总原则

前台页面统一采用「干净、大方、轻科技感」的现代风格。设计目标不是堆叠特效，而是通过留白、比例、微动效、玻璃质感卡片、细腻边框和轻微渐变，让站点看起来更高级、更可信、更适合个人品牌展示。

#### 4.0.1 设计关键词

- **简单**：减少装饰，突出内容层级。
- **大方**：大留白、清晰分区、不过度拥挤。
- **科技感**：使用轻微网格背景、细线、圆角、玻璃卡片、低饱和渐变、微动效。
- **可读**：正文宽度、字号、行高、对比度优先。
- **可维护**：页面组件模块化，后台可配置。

#### 4.0.2 色彩建议

默认浅色主题：

```text
背景：#F8FAFC / #F7F9FC
卡片：#FFFFFF / 半透明白
主色：#6366F1 或后台自定义
强调色：#14B8A6 / #F59E0B
文字主色：#111827
文字次要：#4B5563
辅助文字：#9CA3AF
边框：#E5E7EB / #DDE5F2
```

科技感来源不应依赖大面积深色，而是来自：

- 细线网格。
- 轻微蓝紫渐变。
- 玻璃拟态卡片。
- 圆角 16px - 24px。
- 低透明度光斑。
- 按钮和标签的精致描边。

#### 4.0.3 动效原则

- 首屏只允许轻量动效。
- Hover 动效控制在 150ms - 250ms。
- 卡片上浮不超过 4px。
- 背景光斑可轻微移动，但必须尊重 `prefers-reduced-motion`。
- 文章详情页阅读进度条可常驻顶部。
- 列表页切换分页时可使用骨架屏，不使用重动画。

#### 4.0.4 通用页面结构

所有前台页面建议遵循统一结构：

```text
页面背景装饰层
  ↓
顶部导航栏
  ↓
页面主容器 max-width: 1200px
  ↓
页面 Hero / 面包屑 / 标题区
  ↓
主要内容区
  ↓
页脚
  ↓
移动端悬浮操作栏，可选
```

桌面端最大内容宽度建议为 `1200px`，正文阅读区建议控制在 `680px - 780px`。移动端所有页面改为单列，导航折叠为抽屉式菜单，底部可增加「搜索 / 目录 / 回顶部」悬浮操作栏。

> **注：首页已全面重新设计，本文节仅保留概述，完整规格请参见 `docs/blog-platform/16-homepage-redesign.md`。**

### 4.1.1 页面定位

首页不是单纯的文章列表，而是「个人品牌入口 + 内容精选入口」。2026 年的首页应更像一张有节奏感的数字名片：第一眼知道你是谁、你擅长什么、这里有什么值得读；继续向下滚动时，逐步看到精选内容、项目作品和联系方式。

| 维度 | 规格 |

| 最新 | 列表形式，小封面 + 分类徽章 + 标签块 |
| 项目 | 2 列横排卡片 |
| 交互 | Dark Mode 切换、滚动渐入、骨架屏、回到顶部 |

## 4.2 文章列表 `/articles`

> **注：列表页已全面重新设计，本文节仅保留概述，完整规格请参见 `docs/blog-platform/15-list-page-redesign.md`。**

### 4.2.1 页面定位

文章列表页承担「内容检索」和「内容发现」两个目标。2026 年的列表页不应只是密密麻麻的卡片，而应该让访客快速判断：

- 这里有哪些主题。
- 哪些文章值得先读。
- 如何通过分类、标签、搜索快速缩小范围。
- 列表是否适合当前设备阅读。

### 4.2.2 设计总览

| 维度 | 规格 |
|------|------|
| 默认视图 | 卡片网格（统一宽高），2 列 / 侧边栏收起时 3 列自动切换 |
| 备选视图 | 列表模式（紧凑行），与卡片共用数据，通过按钮切换 |
| 右侧栏 | 可折叠 150px 侧边栏：多级分类树（2 级）+ 标签云 |
| 搜索条 | 搜索框 + 分类下拉 + 排序 + 搜索按钮（sticky） |
| 状态持久化 | 所有筛选条件通过 URL 参数保存（可分享/刷新不丢） |
| 加载态 | 骨架屏（卡片/列表两种模式） |
| 空状态 | 友好空结果 + 推荐分类 |
| 详细规格 | → `docs/blog-platform/15-list-page-redesign.md` |

## 4.3 文章详情 `/articles/[slug]`

> **注：详情页已全面重新设计，本文节仅保留概述，完整规格请参见 `docs/blog-platform/14-detail-page-redesign.md`。**

### 4.3.1 页面定位

文章详情页是前台最重要的阅读场景，也是 SEO 权重的核心页面。2026 年的文章详情页应该「安静、专注、可信」：不要用过重装饰干扰阅读，而是通过清晰层级、舒适字号、稳定目录、轻量互动和精致的阅读工具提升体验。

### 4.3.2 设计总览

| 维度 | 规格 |
|------|------|
| 布局 | **双栏布局**：正文区 ~75% + 右侧栏 220px |
| 目录 | **浮动 TOC**：左侧 28×28px 按钮，点击展开 140px 浮动面板 |
| 右侧栏 | 操作（分享/收藏/复制）+ 分类导航 |
| 标签 | 文章底部标签区，可点击跳转 |
| 评论区 | 完整反灌水规则（验证码 · IP限频 · 内容过滤 · 审核后可见） |
| 正文宽度 | 最大 900px（比原来 780px 更宽） |
| Dark 模式 | 自动跟随系统，完整色值表 |
| 详细规格 | → `docs/blog-platform/14-detail-page-redesign.md` |

## 4.4 自定义页面 `/[customPageSlug]`

> **注：自定义页面已补充细化设计，完整规格请参见 `docs/blog-platform/18-custom-page.md`。**

### 设计概述

自定义页面是轻量内容展示页，仅保留导航 + 页面标题 + 正文 + 页脚。

| 与文章详情页对比 | 说明 |
|-----------------|------|
| 导航栏 | ✅ 复用 |
| 阅读进度条 / Hero / TOC / 侧栏 / 标签 | ❌ 全部去掉 |
| 正文 | ✅ Markdown 渲染，最大宽度 900px |
| 评论区 | ✅ 可选，后台配置 |
| 页脚 / 回到顶部 | ✅ 复用 |

### 功能

- 后台创建的自定义页面通过唯一 slug 访问。
- 支持 Markdown 内容渲染。
- 支持自定义封面图和摘要。
- 支持独立 SEO 信息。
- 展示阅读数量。
- 支持评论区（通过 Layout 模块控制是否开启评论）。

### 路由

```text
GET /[customPageSlug]
```

### SEO

- title 使用页面 SEO 标题。
- description 使用页面 SEO 描述。
- canonical 使用页面正式 URL。
- 自动加入 Sitemap。

### 组件

- `PageContent`
- `PageCover`
- `CommentArea`

## 9. 响应式设计

### 桌面端（≥ 1024px）

- 最大内容宽度：1200px。
- 左右边距：24px。
- 文章正文最佳阅读宽度：680px - 780px（居中对齐或左侧对齐）。
- 三端断点：`sm: 640px`、`md: 768px`、`lg: 1024px`、`xl: 1280px`。
- 首页多模块可并行展示（如 Hero + 精选 + 最新并存于首屏区域）。
- 文章详情页采用双栏布局 + 浮动目录（详见 `14-detail-page-redesign.md`）。
- 导航横向展示，带二级下拉菜单。

### 平板端（768px - 1023px）

- 最大内容宽度：96%。
- 左右边距：20px。
- 列表卡片改为双列网格。
- 目录折叠为可展开侧栏或顶部标签。
- 导航横向展示但限制可见项数，多余项放入 "更多" 下拉。
- 触控区域不小于 44px × 44px。

### 手机端（< 768px）

- 最大内容宽度：100%。
- 左右边距：16px。
- 导航折叠为汉堡菜单，点击展开抽屉式导航。
- 所有列表改为单列。
- 首页模块简化显示（如 Hero 只显示标题和一张图，不显示多个模块并列）。
- 文章正文单列，目录折叠到顶部或底部。
- 评论区单列。
- 页脚垂直排列。
- 底部固定或悬浮式操作栏（如回到顶部、搜索入口）。

## 10. 视觉与主题设计

### 10.1 整体视觉风格

- 2026 年审美趋势：干净、克制、轻科技感、高可读性。
- 建议设计元素：
  - 柔和渐变背景（例如浅蓝到浅紫或浅咖到浅灰）。
  - 玻璃拟态卡片（`backdrop-filter: blur()` + 半透明背景）。
  - 细腻阴影（`box-shadow` 多层或 `drop-shadow`）。
  - 圆角模块（`border-radius: 12px - 20px`）。
  - 科技感几何线条或网格装饰（微妙的 SVG 背景图案）。
  - 高对比文字层级（正文 #1f2937，二级 #4b5563，辅助 #9ca3af）。
  - 浅色模式为主，可配合深色模式。

### 10.2 主色调自定义

- 后台配置主色值，前台通过 CSS 变量应用：

```css
:root {
  --color-primary: #6366f1;          /* 后台配置 */
  --color-primary-light: #a5b4fc;
  --color-primary-dark: #4f46e5;
  --color-bg: #f8fafc;
  --color-surface: #ffffff;
  --color-text: #1f2937;
  --color-text-secondary: #4b5563;
  --color-border: #e5e7eb;
  --color-accent: #f59e0b;
}
```

- 导航栏、按钮、链接、选中态、标签、滚动条等统一应用 `--color-primary`。
- 主色变化不应影响可读性和可访问性（保证对比度）。

### 10.3 字体

- 中文：系统字体（`-apple-system`, `PingFang SC`, `Noto Sans SC` 等）。
- 英文/代码：`Inter`、`JetBrains Mono`。
- 字号层级：标题 2rem-2.5rem，副标题 1.25rem-1.5rem，正文 1rem-1.125rem，辅助 0.875rem。

## 11. 导航与页脚组件规范

### 11.1 导航栏

- 组件 `Navbar` 从 `GET /api/navigation` 获取菜单树。
- 桌面端：水平排版，支持二级下拉菜单。
- 移动端：汉堡菜单展开为全屏或侧边抽屉。
- 当前页面高亮。
- 管理员可见编辑入口（可选）。

### 11.2 页脚

- 组件 `Footer` 从 `GET /api/footer` 获取所有区块。
- 必需区块：
  - 版权说明。
  - ICP 备案号（跳转至工信部链接）。
  - 公安网备案号（跳转至公安备案链接）。
  - 友情链接区块（如有）。
  - 社交链接图标。
  - 联系方式。
  - 站点地图链接。
  - RSS 订阅链接（如有）。
  - 隐私政策 / 免责声明（如后台配置）。
- 区块支持后台启/停和自定义顺序。

## 12. 访问统计

### 12.1 阅读数展示

- 文章详情页、自定义页面、分类页等展示阅读数量。
- 数据来源：业务表 `view_count` 字段。

### 12.2 前台访问上报

- 页面加载后异步调用 `POST /api/visits/track`。
- 使用 `navigator.sendBeacon()` 或在 Next.js 服务端中间件中上报。
- 不阻塞页面渲染，不影响 SEO。
- 服务端做去重（同 IP + 同页面 + 5 分钟内不重复计数）。
