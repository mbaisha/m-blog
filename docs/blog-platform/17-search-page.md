# 17. 搜索结果页设计规格

> 本文档基于 `15-list-page-redesign.md` 的列表页设计，描述搜索结果页的差异与复用规则。
> 搜索页路由：`/search?q=关键词&category=&tag=&page=&view=`

---

## 1. 与列表页的关系

搜索结果页**复用列表页的完整布局和组件**，仅在以下方面有差异：

| 维度 | 列表页 | 搜索结果页 |
|------|--------|-----------|
| URL | `/articles?...` | `/search?q=xxx&...` |
| 页面标题 | 「文章」 | 「搜索」 |
| 搜索条 | 空状态，placeholder | **预填关键词** |
| 结果行 | 「前端架构 · 8 篇文章」 | 「"关键词" 的搜索结果 · 12 篇」 |
| 关键词高亮 | 无（列表页无搜索时不高亮） | **标题/摘要中高亮匹配词** |
| 空状态 | 「没有匹配的文章」 | 「未找到 "关键词" 的相关文章」 |
| Hero 描述 | 固定描述 | 动态：「共找到 X 篇相关文章」 |
| 分类侧栏 | 显示全部分类 | 同列表页，不受搜索影响 |
| 标签云 | 显示所有标签 | 同列表页 |

**其余所有布局、组件、交互逻辑与列表页完全一致**：

- 右侧可折叠侧边栏（分类树 + 标签云）
- 卡片/列表双视图切换
- 搜索条（搜索框 + 全部分类下拉 + 排序 + 搜索按钮）
- 筛选条件 URL 参数持久化
- 骨架屏加载
- 分页

## 2. 搜索页 Hero

```
搜索

"React" 的搜索结果

共找到 12 篇相关文章 · 用时 0.3 秒
```

| 元素 | 规格 |
|------|------|
| 页面标题 | "搜索"，20px，font-weight: 500 |
| 搜索关键词 | `"关键词"`，15px，主色 `#6366F1` + 引号 |
| 结果统计 | "共找到 12 篇相关文章 · 用时 0.3 秒"，11px，`#9CA3AF` |

## 3. 搜索条预填

进入搜索页时，搜索条中的输入框**自动填入用户搜索的关键词**：

```
┌─────────────────────────────────────────────────────────┐
│ 🔍 React   全部分类 ▼   排序 ▼   [ 搜索 ]   [▦] [☰] │
└─────────────────────────────────────────────────────────┘
```

用户可以直接修改关键词重新搜索。

---

## 4. 关键词高亮

在卡片和列表模式中，匹配的关键词用 `<mark>` 标签包裹：

**卡片模式**：
```
┌──────────┐
│  封面图   │
│  [前端]   │
│  从零搭建博客平台：使用  │
│  React 和 Next.js     │  ← "React" 紫底高亮
│  前端 · 06-07 · 📍1,284│
│  React  Next.js       │  ← 标签中的 "React" 也高亮
└──────────┘
```

**列表模式**：
```
从零搭建博客平台：使用 React 和 Next.js  ← "React" 紫底高亮
前端架构 · 06-07 · 📍1,284 · 8 分钟
```

**高亮样式**：
```css
mark.search-highlight {
  background-color: #EEEDFE;
  color: #534AB7;
  border-radius: 2px;
  padding: 0 2px;
}
```

- 只在标题和摘要中高亮
- 标签名也高亮
- 不区分大小写
- 使用 `innerHTML` 替换匹配词（需安全处理 XSS）

## 5. 空状态

当搜索无结果时：

```
未找到 "reactt" 的相关文章

建议：
- 检查关键词是否有拼写错误
- 尝试使用更宽泛的关键词
- 试试其他分类或标签

[ 清空搜索 ]  [ 查看全部文章 ]

热门搜索
React  Next.js  TypeScript  Go  Docker
```

- 主标题 16px，`#374151`
- 建议文字 13px，`#6B7280`
- 按钮用主色描边
- 热门搜索用标签样式展示，点击可快速搜索

## 6. URL 参数

```
/search?q=React&category=frontend&tag=Hooks&sort=popular&page=1&view=grid
```

| 参数 | 必填 | 说明 |
|------|------|------|
| `q` | **是** | 搜索关键词 |
| `category` | 否 | 分类 slug |
| `tag` | 否 | 标签名 |
| `sort` | 否 | 排序方式（默认 `relevance` 相关度）|
| `page` | 否 | 页码（默认 1）|
| `view` | 否 | 视图（`grid`/`list`）|

**排序选项多一个**：`relevance`（相关度），按关键词匹配度排序，默认选中。

---

## 7. 复用组件清单

搜索结果页**不创建新组件**，直接复用列表页组件：

| 组件 | 来源 | 适配 |
|------|------|------|
| `SearchBar` | 列表页 | 预填 `q` 参数 |
| `RightSidebar` | 列表页 | 不变 |
| `CategoryTree` | 列表页 | 不变 |
| `TagCloud` | 列表页 | 不变 |
| `ArticleCard` | 列表页 | 关键词高亮 |
| `ArticleListItem` | 列表页 | 关键词高亮 |
| `ArticleGrid` | 列表页 | 不变 |
| `ArticleListView` | 列表页 | 不变 |
| `ViewToggle` | 列表页 | 不变 |
| `Pagination` | 列表页 | 不变 |
| `Skeleton` | 列表页 | 不变 |
| `EmptyState` | **新建搜索版** | 搜索空状态文案 |
| `SortDropdown` | 列表页 | 增加 `relevance` 选项 |
