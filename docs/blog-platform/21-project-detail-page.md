# 21. 项目详情页设计规格

路由：`/projects/[slug]`

---

## 1. 页面定位

单个项目的详细展示页，包含 Hero、截图、介绍、功能列表。

## 2. 页面结构

```
┌─ Hero ─────────────────────────────────────────┐
│  B   博客平台                                    │
│       基于 Next.js 的现代化个人博客系统           │
│       Next.js  Tailwind  ASP.NET                │
│                              [在线演示] [源代码]  │
│                  完成时间 2026-06 · 个人项目     │
└────────────────────────────────────────────────┘

项目截图
┌──────────────┐ ┌──────────────┐
│  截图 1       │ │  截图 2       │
└──────────────┘ └──────────────┘

项目介绍
（Markdown 渲染内容...）

核心功能
• Markdown 文章编辑与渲染
• 分类标签管理与筛选
• 后台 CMS 内容管理

────────────────────────────────────
页脚
```

## 3. 规格

### Hero 区

| 元素 | 说明 |
|------|------|
| 背景 | 品牌色浅色块 `#EEEDFE`，圆角 14px |
| 图标 | 80×80px 白底方块 + 首字母 |
| 项目名 | 20px，font-weight: 500 |
| 描述 | 12px，`#6B7280` |
| 技术栈 | 白底半透明标签，9px |
| 按钮 | "在线演示" 深色底 / "源代码" 白底灰边框 |
| 元信息 | 完成时间、项目类型，11px |

### 截图区

- 2 列横排，290×140px
- 浅灰底 + 居中文字标注
- 点击可放大查看

### 介绍区

- Markdown 渲染，与自定义页面正文一致
- 核心功能用列表展示
