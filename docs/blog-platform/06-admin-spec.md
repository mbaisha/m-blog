# 06. Vue3 后台管理规格

## 1. 目标

后台管理端面向博主和管理员，目标是提供一个完整、稳定、易用的内容管理系统。

核心能力：

- 登录。
- 仪表盘。
- 文章管理。
- Markdown 编辑。
- 分类标签管理。
- 评论审核。
- 媒体库。
- 个人页面配置。
- 项目展示管理。
- 友情链接管理。
- SEO 配置。
- 数据统计。
- 系统设置。

## 4.13 自定义页面管理 `/pages`

### 功能

## 4.14 导航栏管理 `/navigation`

### 功能

- 菜单列表（树形展示，支持无限层级）。

- 编辑菜单项。
- 删除菜单项。
- 拖拽排序。
- 展开 / 折叠子菜单。

---

## 4.15 页脚管理 `/footer`

### 功能

- 页脚区块列表。
- 编辑每个区块（标题、内容、排序、启用/关闭）。
- 区块类型：
  - 版权说明（纯文本）。
  - ICP 备案（链接 + 文本）。
  - 公安网备案（链接 + 文本）。
  - 社交链接（图标 + URL 列表）。
  - 联系方式（支持邮箱、微信、电话等）。
  - 自定义区块（标题 + 富文本/Markdown）。
- 区块排序。
- 新增自定义区块。
- 删除自定义区块。

---

## 4.16 布局管理 `/layout`

### 功能

- 选择页面类型（首页 / 文章列表 / 文章详情 / 分类 / 标签 / 项目 / 自定义页面）。
- 模块列表（当前类型下所有可用模块，树形或列表展示）。
- 每个模块配置：
  - 启用 / 关闭。
  - 排序（拖拽）。
  - 标题（可自定义显示标题）。
  - 数据源（例如精选文章数量、布局样式等）。
  - 显示选项（例如网格/列表、单列/多列、是否显示封面）。
- 恢复默认布局。
- 实时预览布局效果（可选，通过 iframe 或截图）。

---

## 4.17 主题配置 `/theme`

### 功能

- 主色选择器（颜色选择器或预设色板）。
- 站点名称。
- 站点描述。
- 站点 Logo 上传。
- 站点图标（favicon）上传。
- 预览效果。

---

## 4.18 访问者记录 `/visits`

### 功能

- 访问记录列表（时间、页面路径、IP Hash、User-Agent、Referer、设备类型）。
- 按时间范围筛选。
- 按页面类型筛选（文章 / 自定义页面 / 分类 / 标签 / 项目）。
- 按关键词搜索路径。
- 查看单条访问详情。
- 手动清理（输入保留天数）。
- 自动清理策略配置（系统设置中配置保留天数，后台定时任务每日执行）。
- 阅读数统计图表：按日 / 周 / 月查看趋势。
- 热门页面排名。

---

## 4.19 系统设置 `/settings`

### 功能

- 网站基本信息（名称、描述、Logo、Favicon）。
- 访问记录保留天数（默认 30 天）。
- 自动清理开关。
- 评论审核开关（开启后所有评论默认进入审核）。
- 注册开关（后续扩展）。


- 访问趋势。
- 热门文章。
- 评论趋势。
- 搜索关键词。
- 设备分布。
- 来源页面。

## 5. 权限规范

### 5.1 前端权限

- 未登录不能访问后台页面。
- 无权限菜单不显示。
- 无权限接口调用被拒绝时跳转 403。

### 5.2 后端权限

- 前端权限只用于体验优化。
- 后端权限校验是最终安全边界。

---

## 6. 交互规范

- 所有删除操作必须二次确认。
- 所有保存操作必须有 loading 状态。
- 所有表单必须有校验提示。
- 所有上传必须有进度反馈。
- 所有错误必须有友好提示。
- 所有批量操作必须显示结果。

## 8. Markdown 编辑器规范

### 8.1 必选能力

- Markdown 编辑。
- 实时预览。
- 代码高亮。
- 图片上传。
- 拖拽上传。
- 自动保存草稿。

### 8.2 可选能力

- Markdown 导入导出。

---

## 9. 上传规范

- 图片上传前校验格式和大小。
- 视频上传前校验格式和大小。
- 上传失败需要重试。
- 上传成功返回 URL。
- 上传组件需要支持进度条。

---

## 10. 后台验收标准

- 管理员可以登录。
- 所有菜单可正常访问。
- 文章可新建、编辑、发布、删除。
- Markdown 编辑器可用。
- 图片上传可用。
- 视频上传可用。
- 评论审核可用。
- 媒体库可用。
- 个人页面可配置。
- 项目展示可管理。
- SEO 可配置。
- 权限控制有效。
