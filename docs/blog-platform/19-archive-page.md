# 19. 归档页设计规格

路由：`/archive`

---

## 1. 页面定位

按时间倒序展示所有文章，方便访客按年月浏览全部内容。

## 2. 页面结构

```
归档
共 42 篇文章 · 3 年

2026 · 16 篇文章
● 6 月
│  从零搭建现代博客平台          06-07
│  微服务架构设计实践            06-05
│  产品需求文档怎么写            06-03
● 5 月
│  《代码大全》读书笔记          05-28
│  LLM 应用开发入门             05-25

2025 · 8 篇文章
...

────────────────────────────────────
页脚
```

## 3. 规格

| 元素 | 说明 |
|------|------|
| 页面标题 | "归档"，20px，font-weight: 500 |
| 统计行 | "共 X 篇文章 · Y 年"，12px，`#6B7280` |
| 年份标题 | 18px，font-weight: 500，右侧文章数 |
| 时间线 | 2px 灰色竖线 `#E5E7EB` |
| 月份节点 | 5px 主色圆点 |
| 月份标签 | 13px，font-weight: 500 |
| 文章行 | 11px，`#6B7280` + 右侧日期 `#9CA3AF` |
| 点击 | 点击文章标题跳转 `/articles/[slug]` |

## 4. 数据

```json
GET /api/archive

{
  "years": [

      "total": 16,

          "articles": [
            { "title": "...", "slug": "...", "publishedAt": "2026-06-07" }
          ]
        }
      ]
    }
  ]
}
```
