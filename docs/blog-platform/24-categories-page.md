# 24. 全部分类页设计规格

路由：`/categories`

---

## 1. 页面定位

展示所有分类，2 列卡片网格。

## 2. 页面结构

```
全部分类

┌────────────────────┐ ┌────────────────────┐
│ ▌ 前端架构  12 篇    │ ▌ 后端开发   8 篇    │
│  React, Next.js...  │  Go, Docker...     │
├────────────────────┤ ├────────────────────┤
│ ▌ 产品设计   6 篇    │ ▌ 读书笔记  15 篇    │

页脚
```

## 3. 卡片规格

| 元素 | 规格 |
|------|------|
| 卡片尺寸 | 290×72px，圆角 10px |
| 左侧竖线 | 6px 宽，品牌色 |
| 分类名 | 15px，font-weight: 500 |
| 描述 | 11px，`#6B7280` |
| 文章数 | 12px，品牌色，右侧对齐 |
| 点击 | 跳转 `/categories/[slug]` |
