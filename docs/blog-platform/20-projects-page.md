# 20. 项目列表页设计规格

路由：`/projects`

---

## 1. 页面定位

展示所有项目作品，2 列卡片网格。

## 2. 页面结构

```
项目
个人作品与开源项目

┌────────────────────┐ ┌────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓        │ │ ▓▓▓▓▓▓▓▓▓▓        │
│ 博客平台             │ │ AI 工具箱           │
│ 基于 Next.js 的博客  │ │ 集成 AI 的命令行工具│
│ Next.js Tailwind   │ │ Python FastAPI     │
│ 查看详情 →  GitHub  │ │ 查看详情 →  GitHub  │
└────────────────────┘ └────────────────────┘

┌────────────────────┐ ┌────────────────────┐
│ 设计系统             │ │ ...                │
│ React Storybook   │ │                    │
└────────────────────┘ └────────────────────┘

────────────────────────────────────
页脚
```

## 3. 卡片规格

| 元素 | 规格 |
|------|------|
| 卡片尺寸 | 290×200px，圆角 12px |
| 封面图 | 高度 100px，品牌色铺底 |
| 项目名 | 16px，font-weight: 500 |
| 描述 | 12px，`#6B7280`，2 行 |
| 技术栈标签 | 8px，彩色标签，与分类品牌色一致 |
| 链接 | "查看详情 →" 主色 + "GitHub" 辅助色 |
